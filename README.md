## ❓ FAQ 常见问题解答

### Q1: 为什么强烈建议“优先按月付费”？
机场需要持续支付高额专线租用与服务器成本。按月付费能将试错成本降至最低，即使第三方服务器发生维护或异常，损失也仅限于当月几元或十几元。

### Q2: 什么是真正物理 IEPL 内网专线？
IEPL（国际专线）是在两地机房之间建立的光缆内网通道。数据流量不过公网 GFW 防火墙检测，因此具备**零丢包、超低延迟、晚高峰不卡顿**的绝对优势。

### Q3: 如何看懂节点倍率 (0.5x, 1.0x, 3.0x)？
实际扣除流量 = 传输数据量 × 节点倍率。0.5x 节点传输 10GB 仅扣除 5GB 流量（适合大文件下载）；3.0x 节点传输 10GB 会扣除 30GB 流量（适合高级游戏专线）。
