# Search Console & Webmaster Tools Setup Guide

## Google Search Console Setup
1. Log in to [Google Search Console](https://search.google.com/search-console).
2. Add Domain property: `jcbijiao.my`.
3. Verify ownership via DNS TXT record or HTML meta tag.
4. Go to **Sitemaps** section and submit: `https://jcbijiao.my/sitemap.xml`.

## Bing Webmaster Tools Setup
1. Log in to [Bing Webmaster Tools](https://www.bing.com/webmasters).
2. Import site setup from Google Search Console or add domain `jcbijiao.my`.
3. Submit Sitemap: `https://jcbijiao.my/sitemap.xml`.
4. Configure IndexNow API key if automated instant indexing is desired.
